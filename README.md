# حكايتنا

موقع ذكريات عربي مبني بملفات HTML وCSS وJavaScript فقط. لا يحتاج إلى Node.js أو API أو إعدادات بناء؛ ارفعي الملفات إلى مستودع GitHub ثم انشري جذر المستودع على Vercel كـ **Other / Static**، من دون Build Command أو Output Directory مخصص.

## محتوى الموقع

- `index.html`: هيكل الصفحة.
- `style.css`: الهوية الزرقاء، المجرة، الحركة والتصميم المتجاوب.
- `script.js`: التفاعلات وبوابة كلمة المرور.
- `config.js`: الذكريات والتواريخ والرسائل والأحلام.
- `assets/images/`: الرسوم والصور.

## تعديل كلمة المرور

عدّلي `ACCESS_PASSWORD` في بداية `script.js`، ثم ارفعي التغيير وانشري الموقع مجدداً.

**تنبيه:** لأن هذا موقع ثابت بالكامل، كلمة المرور والذكريات موجودة ضمن ملفات يرسلها الموقع إلى المتصفح ويمكن للمستخدم التقني استخراجها. شاشة كلمة المرور تمنع العرض العادي فقط ولا توفر خصوصية حقيقية. لا تضعي معلومات أو صوراً خاصة جداً هنا. لحماية حقيقية، يلزم خادم مصادقة وتخزين خاص.
